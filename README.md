# Forza Horizon 6 Speedometer

**Windows 보조 모니터용 속도계와 로컬 음악 플레이어**

Forza Horizon 6의 Data Out을 받아 아날로그·디지털 속도계와 RPM을 표시합니다. 계기판은 화면 하단에, 음악 재생바는 계기판 바로 위에 배치됩니다.

> 개인이 제작한 비공식 프로젝트입니다. Microsoft, Xbox, Playground Games 및 Forza의 공식 제품이 아니며, 해당 업체와 제휴하거나 후원받지 않습니다.

## 주요 기능

- **아날로그 + 디지털 속도계** — 0~400 km/h 눈금과 숫자 속도 표시
- **RPM 표시** — 엔진 회전수와 단계별 RPM 막대
- **보조 모니터 지원** — 전체 화면 전환 및 모니터 간 이동
- **수신 상태 안내** — 연결 대기, 주행 대기, 수신 중단, 오류 표시
- **로컬 음악 재생** — MP3·WAV, 이전/다음 곡, 재생 위치 이동, 음량 조절
- **음악 전역 단축키** — 게임 창에 초점이 있어도 음악 조작 가능

400 km/h를 넘으면 바늘은 끝 눈금에 머물고 숫자는 실제 속도를 계속 표시합니다. 수신이 끊기거나 주행 대기 상태가 되면 바늘과 숫자를 숨깁니다.

## 실행 환경

| 항목 | 요구 사항 |
| --- | --- |
| 운영체제 | Windows PC |
| Python | 3.10 이상, Tcl/Tk 포함 |
| 게임 | Forza Horizon 6, Data Out 활성화 |
| 모니터 | 1대 이상, 보조 모니터 사용 권장 |
| 추가 패키지 | 없음 — Python 표준 라이브러리 사용 |

프로그램 자체에는 인터넷 연결이나 계정이 필요하지 않습니다. 기본 설정은 **게임과 속도계를 같은 PC에서 실행**하는 구성입니다.

## 빠른 시작

### 1. 파일 준비

저장소를 다운로드하거나 복제합니다. ZIP으로 받았다면 먼저 압축을 풀어주세요.

[Python 공식 사이트](https://www.python.org/downloads/windows/)에서 Python 3.10 이상을 설치합니다. 설치 시 **Tcl/Tk**를 포함하고, 제공되는 경우 **Add Python to PATH**를 선택하세요.

### 2. 게임 설정

게임의 **설정 → HUD 및 게임플레이 → Data Out**에서 다음 값을 설정합니다.

| 설정 | 값 |
| --- | --- |
| Data Out / 데이터 출력 | On / 켜기 |
| Data Out IP Address | `127.0.0.1` |
| Data Out IP Port | `5301` |

FH6은 고정 패킷 형식을 사용하므로 별도 포맷 선택이 필요 없습니다. 기본 포트는 게임이 사용하는 `5200~5300` 범위를 피해 `5301`로 설정했습니다. [공식 Data Out 문서](https://support.forza.net/hc/en-us/articles/51744149102611-Forza-Horizon-6-Data-Out-Documentation)

### 3. 실행

**START.bat**을 더블클릭한 뒤 게임으로 돌아가 주행합니다.

- 보조 모니터가 있으면 기본적으로 보조 모니터 전체 화면으로 시작합니다.
- 모니터가 하나이면 창 모드로 시작합니다.
- 보조 모니터를 사용할 때는 Windows 디스플레이 설정을 **확장**으로 설정하세요.
- 메뉴 등 데이터가 전송되지 않는 상태에서는 속도가 표시되지 않습니다.

## 화면 조작

아래 단축키는 **속도계 창에 초점이 있을 때** 작동합니다.

| 단축키 | 동작 |
| --- | --- |
| F11 | 전체 화면 / 창 모드 전환 |
| Esc | 전체 화면에서 창 모드로 돌아가기 |
| M | 모니터 재감지 및 다음 화면으로 이동 |
| Ctrl+Q | 프로그램 종료 |

화면 오른쪽 아래 **종료** 버튼으로도 닫을 수 있습니다. 창 모드에서 원하는 모니터로 창을 드래그한 후 F11을 눌러도 됩니다.

## 로컬 음악

1. 프로그램 폴더 안의 **MUSIC** 폴더에 MP3 또는 WAV 파일을 넣습니다. 폴더가 없으면 실행 시 자동으로 생성됩니다.
2. 실행 중 파일을 추가했다면 재생바의 **새로고침**을 누릅니다.
3. **재생**을 누릅니다.

음악은 파일명 순서로 재생하며, 마지막 곡 다음에는 첫 곡으로 돌아갑니다. 시작 시 자동 재생하지 않으며 하위 폴더는 검색하지 않습니다.

- 곡 제목은 파일명을 기준으로 표시합니다.
- 진행 막대를 클릭하거나 드래그하면 재생 위치를 이동합니다.
- 음량은 이 프로그램에서 재생하는 음악에만 적용됩니다.
- 새로고침하면 현재 재생이 멈추고 목록을 다시 읽습니다.
- 재생할 수 없는 파일은 오류를 표시합니다. **다음**으로 다른 곡을 선택하세요.

### 음악 단축키

프로그램 실행 중에는 아래 **전역 단축키**를 사용할 수 있습니다. 종료하면 단축키 등록도 해제됩니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl+Alt+P | 재생 / 일시정지 |
| Ctrl+Alt+← | 이전 곡 |
| Ctrl+Alt+→ | 다음 곡 |
| Ctrl+Alt+↑ / ↓ | 음량 5% 올리기 / 내리기 |

다른 프로그램이 같은 단축키를 사용하면 등록 실패 안내가 표시됩니다. 이 경우 화면 버튼을 사용하세요. 게임 전체 화면에서의 단축키 동작은 사용 환경에 따라 확인이 필요합니다.

G29는 기존처럼 게임에 연결해 사용합니다. 음악 단축키는 Windows에서 직접 받으며, G29 버튼을 음악 조작에 연결하는 기능은 포함하지 않습니다.

## 실행 옵션

프로그램 폴더에서 터미널을 열어 실행합니다.

```powershell
# 기본 실행
py -3 -B speedometer.py

# 창 모드로 실행
py -3 -B speedometer.py --windowed

# 주 모니터에서 실행
py -3 -B speedometer.py --monitor 1 --windowed

# 모니터가 하나여도 전체 화면으로 실행
py -3 -B speedometer.py --fullscreen

# 수신 포트 변경
py -3 -B speedometer.py --port 5401

# 음악 폴더 지정
py -3 -B speedometer.py --music-dir "D:/Music"
```

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `--host` | `127.0.0.1` | UDP 수신 주소 |
| `--port` | `5301` | UDP 수신 포트 |
| `--monitor` | `2` | 사용할 모니터 번호 |
| `--music-dir` | 프로그램 폴더의 `MUSIC` | 로컬 음악 폴더 |
| `--windowed` | 꺼짐 | 창 모드로 시작 |
| `--fullscreen` | 꺼짐 | 모니터가 하나여도 전체 화면으로 시작 |

`--monitor 1`은 주 모니터, `--monitor 2`는 첫 보조 모니터입니다. Windows 설정의 화면 번호와 다를 수 있으며, 없는 번호를 지정하면 마지막 화면을 사용합니다. `--windowed`와 `--fullscreen`은 함께 사용할 수 없습니다.

포트를 변경했다면 게임의 Data Out 포트도 같은 값으로 변경하세요. `START.bat`에도 같은 옵션을 전달할 수 있습니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 연결 대기 | Data Out 활성화, IP·포트 일치 여부를 확인한 뒤 실제로 주행하세요. |
| 수신 중단 | 1.5초 이상 데이터가 들어오지 않은 상태입니다. 메뉴나 일시정지를 끝내고 주행하면 자동으로 재연결됩니다. |
| 데이터 형식 확인 | FH6의 324바이트 패킷만 지원합니다. 다른 게임 또는 변경된 형식은 지원하지 않습니다. |
| 연결 오류 | 속도계가 중복 실행 중인지, 다른 프로그램이 같은 포트를 쓰는지 확인하세요. |
| 설정이 맞아도 수신되지 않음 | Windows 방화벽에서 해당 Python 프로그램의 수신 허용 여부를 확인하세요. |
| 음악 목록이 비어 있음 | MUSIC 폴더 바로 안에 MP3·WAV가 있는지 확인한 뒤 새로고침하세요. |
| 음악 재생 오류 | 다른 파일로 시도하세요. 파일 인코딩과 Windows 재생 지원에 따라 호환성이 달라질 수 있습니다. |
| Python 또는 Tk 오류 | Python 3.10 이상인지 확인하고 `py -3 -m tkinter`로 Tk 창이 열리는지 확인하세요. |

## 프로젝트 구성

```text
forza-speedometer/
├── START.bat          # Windows 실행 스크립트
├── speedometer.py     # 게임 데이터 수신 및 계기판
├── music_player.py    # 로컬 음악 재생 및 전역 단축키
├── README.md          # 사용 안내
└── MUSIC/             # 사용자 음악 폴더 — 실행 시 생성
```

두 Python 파일은 같은 폴더에 보관해야 합니다. 음악 파일은 사용자가 별도로 준비하며, 저장소에 업로드하지 마세요.

## 동작 및 검증 범위

수신 스레드는 최신 데이터 하나만 보관하고 화면은 약 30회/초 갱신합니다. 패킷 길이, 비정상 수치, NaN·무한대 값을 검사하며 수신 중단 시 표시를 비웁니다.

현재 PC에서 확인한 항목:

- Python 문법 및 모듈 로딩
- 합성 패킷의 속도 변환과 실제 로컬 UDP 수신
- 데이터 수신 중단 처리
- 로컬 WAV 재생·일시정지·재생 위치 이동
- 여러 창 크기에서의 계기판·재생바 배치

실제 FH6 주행, Windows 듀얼 모니터 전환, 게임 전체 화면에서의 단축키, 다른 PC의 MP3 재생 호환성은 별도 확인이 필요합니다. 테스트 파일과 가상 주행 데모는 현재 배포 구성에 포함하지 않습니다.
